# لقطة

محرر فيديو عربي يشتغل بالكامل داخل المتصفح، بدون سيرفر وبدون تثبيت. ملفاتك ما تطلع من جهازك.

## المزايا

- **الخط الزمني:** مسارات للنص والفيديو والصوت، قص وتقسيم وتكرار وحذف، وتغيير الترتيب بالسحب، وتراجع وإعادة.
- **النصوص:** خطوط عربية، ورفع خط من جهازك (TTF / OTF / WOFF)، وقوالب جاهزة، وإطار وظل ونيون، وحركات دخول وخروج.
- **الصوت:** استخراج الصوت من فيديو، ومكتبة موسيقى ومؤثرات مصنوعة داخل الموقع، ومستوى الصوت، وظهور واختفاء تدريجي.
- **الكي فريم:** للموقع والحجم والدوران والشفافية، مع 14 منحنى حركة جاهز ومنحنى مخصص.
- **الفلاتر والانتقالات والسرعة والستيكرات.**
- **المقاسات:** 9:16 و16:9 و1:1 و4:5.
- **الوضع الليلي والصباحي.**
- **حفظ تلقائي** للمشروع في المتصفح (IndexedDB).
- **التصدير:** MP4 على Chrome وEdge، وWebM على باقي المتصفحات.

## التشغيل

افتح `index.html` في المتصفح مباشرة. أو فعّل GitHub Pages من إعدادات المستودع:
Settings ← Pages ← Branch: `main` ← Save، وبعدها يصير لك رابط للموقع.

## ملاحظات

- التصدير يصير بالوقت الحقيقي، يعني فيديو دقيقة يحتاج دقيقة تقريباً.
- الفلاتر ما تشتغل على Safari.
